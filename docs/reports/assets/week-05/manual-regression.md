# Фінальний чекліст ручної регресії Week 5

Практичний чекліст для фінальної перевірки MVP QA Deck. Перевірка виконувалась вручну в окремому контрольованому середовищі, без використання робочих файлів, реальних ліцензій і логів або робочих, виробничих чи сторонніх ключів Registry. Для змін Registry використовувався лише окремий контрольований тестовий ключ `HKCU\Software\QADeckManualRegression`.

Орієнтовна тривалість повного проходження: 30-45 хвилин.

## Підготовка контрольованого тестового середовища

Для ручної перевірки використовувались два окремі продукти:

- `Week5 Manual`
- `Week5 Companion`

Тестові файли зберігались у `%TEMP%\qa-deck-week5-manual`.

Для Registry використовувався тільки окремий ключ:

`HKCU\Software\QADeckManualRegression`

Початковий стан:

- `Mode`, тип `REG_DWORD`, значення `7`
- підрозділ `Feature` з контрольним значенням `Sentinel`
- `MissingMode` відсутній
- `license.dat` активний
- `license.dat.hidden` відсутній
- тестові логи знаходяться в окремому каталозі

### Підготовка у PowerShell

```powershell
$root = Join-Path $env:TEMP "qa-deck-week5-manual"
$appRoot = Join-Path $root "app"
$licenseRoot = Join-Path $root "licenses"
$logRoot = Join-Path $root "logs"
$licenseActive = Join-Path $licenseRoot "license.dat"
$licenseHidden = Join-Path $licenseRoot "license.dat.hidden"
$registryRoot = "HKCU:\Software\QADeckManualRegression"
$featureKey = Join-Path $registryRoot "Feature"
$hiddenFeatureKey = Join-Path $registryRoot "Feature.__qa_deck_hidden__"

if ((Test-Path -LiteralPath $featureKey) -and
    (Test-Path -LiteralPath $hiddenFeatureKey)) {
  Write-Warning "Feature і Feature.__qa_deck_hidden__ існують одночасно. Підготовку зупинено для ручної перевірки конфлікту."
  return
}

New-Item -ItemType Directory -Path $appRoot -Force | Out-Null
New-Item -ItemType Directory -Path $licenseRoot -Force | Out-Null

if (Test-Path -LiteralPath $logRoot) {
  Remove-Item -LiteralPath $logRoot -Recurse -Force
}
New-Item -ItemType Directory -Path $logRoot -Force | Out-Null

Copy-Item -LiteralPath "C:\Windows\System32\notepad.exe" `
  -Destination (Join-Path $appRoot "sample.exe") -Force

if (Test-Path -LiteralPath $licenseHidden -PathType Leaf) {
  Remove-Item -LiteralPath $licenseHidden -Force
}

Set-Content -LiteralPath $licenseActive `
  -Value "Harmless QA Deck demo license text." -Encoding UTF8

1..4 | ForEach-Object {
  Set-Content -LiteralPath (Join-Path $logRoot ("sample-{0}.log" -f $_)) `
    -Value ("Harmless QA Deck demo log {0}." -f $_) -Encoding UTF8
}

New-Item -Path $registryRoot -Force | Out-Null
New-ItemProperty -Path $registryRoot -Name "Mode" `
  -PropertyType DWord -Value 7 -Force | Out-Null

if (Test-Path -LiteralPath $hiddenFeatureKey) {
  Rename-Item -LiteralPath $hiddenFeatureKey -NewName "Feature"
} elseif (-not (Test-Path -LiteralPath $featureKey)) {
  New-Item -Path $featureKey -Force | Out-Null
}
New-ItemProperty -Path $featureKey -Name "Sentinel" `
  -PropertyType String -Value "QA Deck manual regression" -Force | Out-Null

Remove-ItemProperty -Path $registryRoot -Name "MissingMode" `
  -ErrorAction SilentlyContinue
```

## Відновлення контрольованого стану

Скриншоти та інші докази змінених станів потрібно зберегти до виконання команд відновлення.

Цей блок повертає явно зарезервовані контрольовані ресурси до початкового стану, але не видаляє весь тимчасовий каталог або кореневий ключ Registry.

```powershell
$root = Join-Path $env:TEMP "qa-deck-week5-manual"
$licenseRoot = Join-Path $root "licenses"
$licenseActive = Join-Path $licenseRoot "license.dat"
$licenseHidden = Join-Path $licenseRoot "license.dat.hidden"
$registryRoot = "HKCU:\Software\QADeckManualRegression"
$visibleFeature = Join-Path $registryRoot "Feature"
$hiddenFeature = Join-Path $registryRoot "Feature.__qa_deck_hidden__"

if ((Test-Path -LiteralPath $visibleFeature) -and
    (Test-Path -LiteralPath $hiddenFeature)) {
  Write-Warning "Feature і Feature.__qa_deck_hidden__ існують одночасно. Відновлення зупинено для ручної перевірки конфлікту."
  return
}

New-Item -Path $registryRoot -Force | Out-Null
New-ItemProperty -Path $registryRoot -Name "Mode" `
  -PropertyType DWord -Value 7 -Force | Out-Null

Remove-ItemProperty -Path $registryRoot -Name "MissingMode" `
  -ErrorAction SilentlyContinue

if (Test-Path -LiteralPath $hiddenFeature) {
  Rename-Item -LiteralPath $hiddenFeature -NewName "Feature"
}

if (-not (Test-Path -LiteralPath $visibleFeature)) {
  New-Item -Path $visibleFeature -Force | Out-Null
}

New-ItemProperty -Path $visibleFeature -Name "Sentinel" `
  -PropertyType String -Value "QA Deck manual regression" -Force | Out-Null

New-Item -ItemType Directory -Path $licenseRoot -Force | Out-Null

if (Test-Path -LiteralPath $licenseHidden -PathType Leaf) {
  if (Test-Path -LiteralPath $licenseActive -PathType Leaf) {
    Remove-Item -LiteralPath $licenseHidden -Force
  } else {
    Rename-Item -LiteralPath $licenseHidden -NewName "license.dat"
  }
}

Set-Content -LiteralPath $licenseActive `
  -Value "Harmless QA Deck demo license text." -Encoding UTF8
```
